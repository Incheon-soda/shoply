# 프로젝트 핸드오프 프롬프트

## 프로젝트 개요

쇼핑몰 MSA를 **온프레미스 K8s(AWS EC2 + KVM) vs AWS EKS** 비교 실험 프로젝트.
발표용 데이터 수집이 목적. 단일 AWS 계정, 두 개 VPC 구성.

## 중요 주의사항

1. **virsh 명령어**: 반드시 `sudo virsh ...` (sudo 없으면 permission denied)
2. **KVM VM DNS**: VM 생성 후 `/etc/resolv.conf` 반드시 8.8.8.8로 교체 (systemd-resolved 불통)
3. **EC2 호스트 DNS**: EC2 호스트도 동일하게 `/etc/resolv.conf` 교체 필요
4. **master VM 접속**: SSH 패스워드 안 되면 `sudo virsh console k8s-master`
5. **매니페스트 적용**: root 접속 시 `~/` = `/root/` → `/home/ubuntu/k8s-manifests/` 절대경로 사용
6. **kube-proxy 패치**: KVM은 LXD와 달리 불필요
7. **liveness probe**: 모든 서비스에 `/livez` 엔드포인트 있어야 함 (없으면 CrashLoopBackOff)
8. **HPA 작동 조건**: metrics-server 필수, `--kubelet-insecure-tls` 플래그 필요
